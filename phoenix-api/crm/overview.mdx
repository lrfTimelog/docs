## Methods

10 operations are declared in the draft contract for this domain.

| Method | Endpoint | What it does |
|---|---|---|
| `GET` | [`/v1/customers`](/phoenix-api/crm/list-customers) | List or search customers |
| `POST` | [`/v1/customers`](/phoenix-api/crm/create-customer) | Create a customer, supplier or lead |

| `PUT` | [`/v1/customers/ext:{ns}:{key}`](/phoenix-api/crm/upsert-customer-by-external-id) | Create or update a customer by your own key |

| `PATCH` | [`/v1/customers/{id}`](/phoenix-api/crm/update-customer) | Change some fields of a customer |
| `DELETE` | [`/v1/customers/{id}`](/phoenix-api/crm/delete-customer) | Delete a customer that nothing references |
| `POST` | [`/v1/customers/{id}:mark-merged`](/phoenix-api/crm/mark-customer-merged) | Mark a customer as merged into a survivor |
| `GET` | [`/v1/customer-statuses`](/phoenix-api/crm/list-customer-statuses) | List customer status labels |
| `GET` | [`/v1/customer-statuses/{id}`](/phoenix-api/crm/get-customer-status) | Get one customer status label |
