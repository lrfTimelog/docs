## Planned resources

From the target API model. Not yet specified as a contract.

| Resource | Type | Priority | Purpose |
|---|---|---|---|
| `invoices` | Resource | MUST | A customer invoice (`InvoiceType = 1`), draft or booked, with embedded lines, for ERP posting, |
| `credit-notes` | Resource | MUST | A credit note (`InvoiceType = 2`) reversing a booked invoice, posted by ERPs as its own document (PD-034). |
| `billable-items` | View | SHOULD | Uninvoiced billable work (invoicing potential) per project/customer/period: "what can we invoice" |
