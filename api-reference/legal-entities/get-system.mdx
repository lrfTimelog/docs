```http
GET /v1/legal-entity/system
```

Returns the site's default legal entity — the one with `IsSystemLegalEntity` set to `true`.
Every TimeLog site has exactly one, including single-company sites.

Use this when an integration needs the site's own currency, country or registered name
and does not care about the other entities. It saves fetching the whole list and
filtering.

## Authorization

<ParamField header="Authorization" type="string" required>
  `Bearer <personal access token>`. See [Authentication](/api-reference/authentication).
</ParamField>

## Response

`200` — a [single-resource envelope](/api-reference/response-format#single-resource).

<ResponseField name="Properties" type="object">
  The system legal entity.
</ResponseField>

<ResponseField name="Links" type="TafLink[]">
</ResponseField>

<ResponseField name="Actions" type="TafAction[]">
</ResponseField>

<Warning>
  **The `Properties` payload is not specified in the API contract.** The envelope is
  documented; the resource inside it is not. Observed responses match the
  `LegalEntityApiReadModel` returned by
  [Get all legal entities](/api-reference/legal-entities/list) — `LegalEntityID`, `ID`,
  `Name`, `IsActive`, `CurrencyISO`, `CountryISO`, `IsSystemLegalEntity` — but that is an
  observation, not a guarantee.

  If you need a shape you can rely on, call
  [Get all legal entities](/api-reference/legal-entities/list) and filter on
  `IsSystemLegalEntity` instead. That endpoint's payload **is** specified.
</Warning>

## Errors

| Code | Cause |
| --- | --- |
| `401` | Invalid authentication token, wrong instance, or wrong account. See [Errors](/api-reference/errors). |
